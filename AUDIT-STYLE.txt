----------------------------------------------------------------------------------------------
WHAT WAS CHANGED
----------------------------------------------------------------------------------------------

Applied in every module where the rule was not already met (per-module detail in the
CHANGE LOG at the end):
  - tabs / trailing whitespace / non-printable bytes removed (raw bytes became \xNN escapes)
  - every line <= 100 columns; comment boxes exactly 99 columns
  - function header boxes reduced to one line; caller-useful text moved to the module .md
  - multi-line inline comments condensed to one line; padding before trailing comments removed
  - Is/Yes/No comments on non-trivial conditionals (one-line ifs braced where needed)
  - each sub-expression of a non-trivial expression parenthesized, macro parameters too
  - one declaration per line
  - private statics renamed to the full module prefix (e.g. _fe_add -> _SSFX25519FeAdd,
    _SSFCCPComputeTag -> _SSFChaCha20Poly1305ComputeTag, _SSFJsonTypeField ->
    _SSFUBJsonTypeField); README.md footnotes updated to match
  - parameters renamed to the Str / Opt / Size / Len suffixes in .c, .h and .md where the role
    was clear (e.g. ASN.1 encoders buf -> bufOpt, JSON js -> jsStr, TLS label -> labelStr)
  - comments removed from assert lines; audit / OPTIMIZE labels and change history removed from
    non-unit-test source comments
  - DBC: 208 SSF_REQUIRE checks added where the condition is already required for defined
    behaviour and no caller violates it (mostly non-NULL pointers in static helpers):
      ssfrsa 65, ssfecdsa 49, ssfaesccm 21, ssfed25519 17, ssfpoly1305 7, ssfec 7, ssfx509 6,
      ssfx25519 5, ssfini 5, ssfchacha20poly1305 5, ssfsha2 4, ssfjson 4, ssfbn 3, ssftls 2,
      ssfsha1 2, ssfgobj 2, ssfaesgcm 2, ssfdec 1, ssfaesctr 1
    No assert was added that rejects an input the code handles gracefully today; those cases
    are findings instead.
  - Timing-critical exception (Jim, 2026-11-20): the passes first added 64 more asserts to
    per-block / per-field-op / per-point-op helpers. Those were removed again, because their
    callers already check the same conditions and they cost speed. See DBC-S1 for the list.

Not changed (recorded as findings): return types, public function / macro / type / field
names, missing init tracking, missing size parameters, behaviour bugs, doc text whose correct
version is a design decision.
