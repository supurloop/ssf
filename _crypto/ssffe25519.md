# ssffe25519 — GF(2²⁵⁵ − 19) Field Arithmetic

[SSF](../README.md) | [Cryptography](README.md)

Field arithmetic modulo p = 2²⁵⁵ − 19, shared by [`ssfx25519`](ssfx25519.md) and
[`ssfed25519`](ssfed25519.md). Both modules used to carry identical private copies of these
functions; a build that links both now carries one (OPTIMIZE FE-O2: about 0.7 KB less on
Cortex-M4, 0.9 KB less on Cortex-M0+).

**Internal module.** The interface exists so the two Curve25519-family modules can share
code. It is not a general-purpose API and may change with them; applications should use
[`ssfx25519`](ssfx25519.md) and [`ssfed25519`](ssfed25519.md).

## [↑](#ssffe25519--gf2²⁵⁵--19-field-arithmetic) Notes

- **Representation.** An element is `SSFFE25519_t`: eight 32-bit limbs, little-endian limb
  order (32 bytes). Every function accepts any value below 2²⁵⁶, so the lazily reduced
  results of [`ssfed25519`](ssfed25519.md)'s add and subtract can be passed straight in.
- **Fully reduced outputs.** [`SSFFE25519Mul()`](#ssffe25519mul),
  [`SSFFE25519Sqr()`](#ssffe25519mul), [`SSFFE25519Reduce()`](#ssffe25519reduce) and
  [`SSFFE25519Inv()`](#ssffe25519inv) return values in [0, p);
  [`SSFFE25519ToBytes()`](#ssffe25519tobytes) writes the canonical encoding.
- **Constant-time.** No function branches on, or indexes memory by, element values: the
  reduction folds its carries unconditionally and selects with masks, and
  [`SSFFE25519CSwap()`](#ssffe25519cswap) swaps with a mask built from the swap bit.
- **What stays in the callers.** Addition, subtraction and decoding differ deliberately
  between the two users (X25519 reduces fully after every add and masks bit 255 on import as
  RFC 7748 requires; Ed25519 keeps adds lazy and handles the sign bit itself), so each module
  keeps its own. Module-specific helpers (`_fe_mul_small` in X25519; `_fe_pow2523`,
  `_fe_isneg`, `_fe_iszero`, `_fe_neg` in Ed25519) stay local too.
- **Square.** [`SSFFE25519Sqr()`](#ssffe25519mul) is `SSFFE25519Mul(r, a, a)`. A dedicated
  36-product square was measured (OPTIMIZE FE-O1) and not adopted: it was 26% faster on
  Cortex-M0+, which has no 32 × 32 → 64-bit multiply, but no faster on Cortex-M4 and slower
  on ARMv7-A and x86-64, where the multiply's tight 8 × 8 loop already dominates.

## [↑](#ssffe25519--gf2²⁵⁵--19-field-arithmetic) Function Reference

<a id="ssffe25519mul"></a>

```c
void SSFFE25519Mul(SSFFE25519_t *r, const SSFFE25519_t *a, const SSFFE25519_t *b);
void SSFFE25519Sqr(SSFFE25519_t *r, const SSFFE25519_t *a);
```

`r = a × b mod p` (or `a²`), fully reduced. Schoolbook 8 × 8-limb product, then `low + 38 ×
high` (2²⁵⁶ ≡ 38), two unconditional carry folds and a final reduction. `r` may alias `a` or
`b`. All pointers must be non-`NULL` (`SSF_REQUIRE`).

<a id="ssffe25519reduce"></a>

```c
void SSFFE25519Reduce(SSFFE25519_t *a);
```

Reduces `a` (any value below 2²⁵⁶) to [0, p) in place: folds bit 255 twice (2²⁵⁵ ≡ 19), then
one masked conditional subtraction of p.

<a id="ssffe25519inv"></a>

```c
void SSFFE25519Inv(SSFFE25519_t *r, const SSFFE25519_t *a);
```

`r = a^(p − 2) mod p`, the inverse for nonzero `a` (0 maps to 0). Fixed addition chain of 255
squarings and 11 multiplications, so its run time does not depend on `a`.

<a id="ssffe25519tobytes"></a>

```c
void SSFFE25519ToBytes(uint8_t *b, const SSFFE25519_t *a);
```

Writes `a`, fully reduced, as 32 little-endian bytes to `b`; `a` is not modified.

<a id="ssffe25519cswap"></a>

```c
void SSFFE25519CSwap(SSFFE25519_t *a, SSFFE25519_t *b, uint32_t swap);
```

Exchanges `a` and `b` when bit 0 of `swap` is set; other bits are ignored. The mask is built
arithmetically, with no branch on `swap`.
